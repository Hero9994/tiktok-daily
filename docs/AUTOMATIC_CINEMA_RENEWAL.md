## شروط القبول

- اكتشاف متجدد من [فهرس مراجعات Common Sense Media](https://www.commonsensemedia.org/reviews/sitemap.xml)، بدايةً من الصفحات الأحدث مع الدوران على بقية الصفحات؛ ليست قائمة أسماء ثابتة.
- تقييم المحرر 4/5 فأعلى، مرتبط بنفس الفيلم أو المسلسل؛ لا تقييم الجمهور أو عمل مشابه.
- دليل المحتوى الجنسي الكامل المنشور، وليس النبذة المختصرة. تُستبعد البيانات الناقصة والمحتويات التي تحتاج مراجعة بشرية. القبول الآلي أضيق من قبول المكتبة المراجعة يدويًا.
- تطابق IMDb بين المراجعة وWikidata، وصفحة Wikipedia المرتبطة بنفس QID. العنوان وحده لا يكفي.
- سنة الإصدار من Wikidata، لا تاريخ المراجعة. لا تُضاف أعمال قديمة دون دليل Top 200؛ التجديد لا يخترع هذا الدليل.
- مقارنة الهوية مع كامل القائمة وسجل الترشيحات، ثم فحص الصورة الفعلية من مضيف مسموح.

أولوية للنوع الأقل عددًا وإشارات اكتشاف عربي عند نقصه، مع التحقق الفعلي من اللغة والبلد لاحقًا. تبقى موازنة المصري والسوري والأفلام والمسلسلات عند اختيار منشور اليوم. لا يُملأ الأجنبي بلا حدود لإخفاء نقص العربي.

**تغطية المصدر الآلي للأعمال المصرية والسورية محدودة**. تُضاف الأعمال العربية والأجنبية التي تتوفر لها مراجعات صالحة؛ لا ندّعي مشاهدة كل مشهد أو وجود دليل محتوى لكل عمل. القائمة العربية الحالية محفوظة. لا يُستخدم ملخص ElCinema وحده لإثبات غياب محتوى جنسي.

## التكلفة والفشل

**صفر طلبات OpenAI إضافية للتجديد**: مصادر عامة وفحوص محلية على GitHub Actions. لا API مدفوع جديد ولا توليد صور. تكلفة إعداد منشور اليوم السابقة مستمرة.

لا يستدعي التجديد Buffer ولا ينشر بوست اختبار. يحتفظ بالمكتبة السابقة عند تعذر المصادر. الفشل الكامل يتيح المحاولة الاحتياطية؛ المحاولة الناجحة التالية في اليوم التالي. `assets/cinema-renewal.json` يوثق الرفض؛ كل عمل مضاف يحفظ النص الداعم وروابط الهوية وبصمة المراجعة. يُعاد فحص المرفوض بعد 30 يومًا، وأخطاء الاتصال لا تُعد رفض محتوى.

مسألة GitHub واحدة تتجدد عند فشل التشغيل أو ثلاث جولات بحث محتاجة دون إضافة. يستمر النشر من المخزون المتاح وتنبيهه السابق. لا ضمان بإضافة يومية عند غياب مصادر كافية.
