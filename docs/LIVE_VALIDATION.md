# توثيق تجربة النشر الفعلية

تاريخ التجربة: 2026-10-14.

تم ربط القناة @tk.player7 عبر Buffer والتحقق من أن القناة متصلة وغير مقفلة وغير موقوفة. مفاتيح الخدمات الثلاثة محفوظة في GitHub Actions Secrets، ولم تحفظ في الكود.

- OpenAI: نجحت المصادقة وتوفّر نموذجا النص والصورة، ونجح التوليد المدفوع الاقتصادي.
- football-data.org: نجح الفحص الحقيقي بالخطة المجانية؛ لم يظهر موعد مؤكد لمباراة يوم 2026-10-15 ضمن البطولات الثماني المختارة، فاختير فيلم Arrival.
- التوليد: طلبان للنص وطلب واحد للصورة فقط. أبعاد بطاقة النشر 1080×1920 JPEG؛ الرسم أصلي وليس بوسترًا رسميًا.
- التصميم: TK، قالب أسود وذهبي، نبذة عربية دون حرق، 5 هاشتاغات، والعبارة الثابتة في نهاية الوصف.
- Buffer: فشل الطلب الأول في تحقق GraphQL قبل التنفيذ بسبب طلب حقل title غير الموجود في TiktokMetadata للحساب. فُحص schema الفعلي وقائمة المنشورات مرتين، ولم يُعثر على منشور مطابق. صُحح الاستعلام وأعيد استخدام الصورة المحفوظة دون طلب توليد إضافي.
- منع التكرار: حُفظت ملاحظة التعافي في السجل، ثم قُبل المنشور مرة واحدة بتاريخ 2026-10-14 وموعد 12:05 بتوقيت ألمانيا، ومعرّفه في Buffer محفوظ في فرع bot-state.

نجح التسليم: أعاد Buffer الحالة `sent` بتاريخ 2026-10-14 الساعة 10:08:44 UTC، مع [رابط منشور TikTok](https://www.tiktok.com/@tk.player7/video/7696462411368369440). فُتح الرابط العام بنجاح HTTP 200، وتحققت بيانات TikTok العامة من الحساب tk.player7، وصورة واحدة، والوصف العربي مع الإفصاح وخمسة هاشتاغات والعبارة الثابتة في نهايته.

نجح [تشغيل التحقق](https://github.com/Hero9994/tiktok-daily/actions/runs/38545238291)، ثم فُعّل `daily_enabled=true` وأُلغي `activate_after_first_success`؛ موعد النشر اليومي 18:00 بتوقيت ألمانيا. الإيقاف اليدوي اللاحق لا يُلغى تلقائيًا. لا تنشئ فحوص التسليم صورًا إضافية ولا منشورات إضافية. الأوصاف تستعمل الإفصاح النصي عن الرسم المولّد لأن العلم الأصلي لصور TikTok غير متاح في Buffer.

اختبارات GitHub Actions: 46 اختبارًا ناجحًا، منها التحقق من عدم تفعيل الجدولة عند accepted، وحفظ تعديلات المالك، واحترام إيقافه للجدولة.
