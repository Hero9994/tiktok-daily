# تجربة الفيديو بالموسيقى والمسارين اليوميين

تاريخ التحقق: 2026-10-14.

- تم حفظ أول 20 ثانية فقط من موسيقى الرياضة Move It Fast وموسيقى السينما Five-Note Motif، في ملفين منفصلين؛ ffprobe أكد مدة كل منهما 20.000 ثانية.
- FFmpeg ينتج 1080×1920 H.264/AAC MP4 مدته 20 ثانية، دون API مدفوع للصوت أو الفيديو. البطاقات المتعددة تعرض بالتتابع.
- الرياضة 16:00، والسينما 18:00 بتوقيت أوروبا/برلين، والتحضير 15:07 و17:07. لكل مسار مفتاح يوم مستقل. منشور Arrival القديم يمنع إعادة نشر السينما اليوم.
- API فيديو Buffer موثق رسميًا، مع video asset وthumbnailOffset=0، وعلم TikTok isAiGenerated للفيديو؛ لا يستعمل عنوان الصور أو موسيقى مكتبة TikTok.
- فشل حفظ checkpoint الأول قبل إرسال أي mutation إلى Buffer. نجحت إعادة التشغيل من السجل؛ لم تُنشأ صورة مدفوعة أو منشورات مكررة. أضيفت محاولات نقل Git آمنة لنفس commit دون force-push، مع التوقف إذا تغير الفرع البعيد.
- تجربة رياضية حقيقية: المصدر لم يعرض مباريات مؤكدة لغد 15 أكتوبر ضمن البطولات المتابعة، لذلك نُشر تحديث يوضح ذلك، بلا مواجهات تجريبية.
- Buffer أعاد sent بتاريخ **2026-10-14T12:55:47.577Z** للمنشور **6acf7b6b86d4961cd67db6ea**. [رابط TikTok](https://www.tiktok.com/@tk.player7/video/7696506064065400096). وصل الرابط العام إلى HTTP 200؛ تأكيد التسليم من Buffer، وترميز الصوت والمدة تحققا قبل الإرسال.
- [تشغيل النشر](https://github.com/Hero9994/tiktok-daily/actions/runs/38566880146) و[التحقق من التسليم](https://github.com/Hero9994/tiktok-daily/actions/runs/38567461110) نجحا. بقيت عدادات OpenAI عند طلب صورة واحد وطلبَي نص من التجربة القديمة، ولم يضف اختبار الرياضة طلب توليد مدفوعًا.
- معاينة السينما بالأغنية الثانية جاهزة محليًا؛ لم ينشر Arrival مرة ثانية. النشر التالي للسينما سيستخدم الموسيقى المخصصة تلقائيًا.
