# تقرير التحقق

التاريخ: 2026-10-13.

- اختبارات محلية: 42 اختبارًا ناجحًا، باستخدام Python 3.12 وPillow 12.0.0 المثبتة في متطلبات المشروع. [الملخص](TEST_RESULTS.txt). تشمل تغيير الوصف والهاشتاغات مع إبقاء العبارة الثابتة في النهاية، ومصدر نبذة العمل، ومنع تكرار معرّف العمل، وعرض العربي، ومواعيد المباريات والصيف/الشتاء وتجاوز منتصف الليل والانتقال إلى السينما فقط عند جدول فارغ مؤكد.
- إنشاء ملفات الصور: تم التحقق من JPEG بقياس **1080×1920**، الإفصاح العربي و5 هاشتاغات.
- Git: إنشاء فرع orphan، commit/push إلى مستودع محلي مؤقت، استعادة السجل والصورة في تشغيل جديد، ورابط صورة مبني على SHA ثابت.
- مباريات الغد: اختبار محاكاة لتغيير وقت مباراة بين الفحص الأول والفحص السابق للإرسال؛ تتحدث الصورة والمواعيد مع بقاء عدد طلبات توليد الخلفية واحدًا. جدول 8 مباريات ينتج صورتين ويحتفظ بكل المباريات.
- Buffer: اختبارات محاكاة لإرسال GraphQL، جدولتها، تأكيد `sent`، أخطاء HTTP 200، التصفح بين الصفحات، منع تكرار اليوم، تعافي نتيجة إرسال غامضة دون إعادة إنشاء المنشور، والتنبيه عند التأخير أو الحاجة للنشر اليدوي. شمل اختبار تكامل خادم HTTP محليًا واتصال HTTP فعليًا عبر محولات OpenAI وBuffer، ثم حفظ الصورة ورابطها واستعادة السجل للتحقق.
- الأمان: الإعدادات الافتراضية توقف التشغيل والإنفاق، ولا تطبع المفاتيح أو ردود الخدمات. Workflow النشر يعمل على الفرع الافتراضي فقط. Workflow اختبارات PR لا يستخدم الأسرار.

للاختبار الفعلي بعد الربط: `publish-test` ثم `verify`، وانتظر `sent`، وافتح `external_link` في حساب TikTok للتحقق بصريًا من الصورة والوصف والهاشتاغات والإفصاح. لا تعاود اختبار الإرسال لنفس التاريخ إذا كانت النتيجة غير مؤكدة.
