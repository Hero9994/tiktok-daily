# بديل الرياضي: آخر نتائج الدوريات الخمس — 2026-10-23

طلب المالك نشر آخر نتائج الدوريات الخمس الكبرى عند غياب مباريات الغد المؤهلة بفلتر الفرق المشهورة، بنفس القالب والموسيقى الرياضية. تفعيل `football_results_fallback: true`.

- الأولوية دائمًا لجدول المباريات المفلتر. لا تُستخدم النتائج عند خطأ المصدر أو موعد غير مؤكد.
- البديل يقرأ football-data.org المجاني؛ فقط PL وPD وBL1 وSA وFL1، وحالة FINISHED، ونتيجة fullTime صحيحة (صفر مسموح، غياب النتيجة لا يتحول إلى صفر).
- نافذة البحث آخر سبعة أيام؛ أحدث يوم مباريات مكتمل متاح لكل دوري، ضمن ما أعاده المصدر. الفرق الكبيرة أولًا، ثم بقية نتائج ذلك اليوم. لا نملأ الفراغ بنتائج أقدم من النافذة. تظهر الدوريات المتاحة فقط؛ نقص دوري لا يعني عدم إقامته مباريات.
- لا تعاد نتيجة مباراة ظهرت سابقًا ضمن منشور نتائج مقبول/مرسل (معرف المباراة، عبر كل التاريخ). سبق الإعلان عن المباراة ضمن جدول الغد لا يمنع نشر نتيجتها لاحقًا. السجل اليومي يمنع الرياضي البديل والجدول من النشر مرتين في اليوم.
- يعاد فحص النتائج قبل الإرسال. تغيّر النتيجة يعيد رسم البطاقات والفيديو. لا تعدّل المنشورات المقبولة أو المرسلة تلقائيًا.
- القالب الأسود والذهبي محفوظ. العنوان «آخر النتائج»، والوصف «الدوريات الخمس الكبرى • نتائج نهائية»، والوسط نتيجة بجانب فريقيها، وتاريخ كل مباراة. التاريخ العلوي تاريخ تحديث المنشور، وليس ادعاء أن جميع المباريات جرت اليوم. لا يعرض توقيتًا أو عنوان مباريات الغد على بطاقة النتائج.
- موسيقى الرياضة السابقة ومدة 20 ثانية وموعد 14:00 ألمانيا والعبارة الثابتة آخر الوصف كما هي. لا طلب OpenAI إضافي، ولا خطة API مدفوعة.
- إذا لم توجد نتائج حديثة جديدة مؤكدة، لا ننشر بطاقة فارغة أو نكرر نتائج سابقة.

معاينة فقط: football-preview.yml مع post_day وresults=true؛ لا مفاتيح Buffer/OpenAI ولا أي نشر. نجحت 117 اختبارات محلية، بما فيها المصدر المعيب، استبعاد الحي/المستقبل/الأقدم، نطاق الدوريات، النتيجة صفر، إزالة التكرار، وعرض النتيجة والتاريخ.
