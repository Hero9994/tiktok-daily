# TK — ناشر يومي للمباريات والأفلام والمسلسلات

ينشر المشروع يوميًا على TikTok عبر Buffer: **جدول مباريات الغد أولًا**، وإذا أثبت المصدر عدم وجود مباريات في البطولات المختارة ينشر **فيلمًا أو مسلسلًا مختلفًا**. القالب أسود وذهبي مع TK؛ الوصف والهاشتاغات يتغيران حسب الموضوع، وتنتهي كل الأوصاف بهذه العبارة حرفيًا:

> شاهدها على سيرفراتنا بجودة عالية وبدون تقطيع ⚡🏆

**التشغيل والإنفاق معطّلان حتى يكتمل الربط.** رفع الملفات واختبارات GitHub تمّا، لكن لم يحدث نشر حقيقي أو إنفاق API. [تقرير الاختبارات](docs/TEST_REPORT.md) و[مراجعة المصادر والتكلفة](docs/VERIFICATION.md).

## المطلوب منك للربط — مرة واحدة

1. افتح [Buffer Free](https://buffer.com/signup)، ثم [Channels](https://account.buffer.com/channels)، واربط TikTok بقبول صلاحية النشر. أنشئ مفتاح Buffer من [Settings → API](https://publish.buffer.com/settings/api).
2. أنشئ مفتاحًا في [OpenAI API](https://platform.openai.com/) وأضف رصيدًا حسب الحد الأدنى الذي يعرضه حسابك. اشتراك ChatGPT لا يشمل API. قد يطلب حسابك توثيق المؤسسة لتوليد الصور.
3. سجّل في [football-data.org](https://www.football-data.org/client/register) واختر **Free €0**، وأنشئ مفتاح البيانات. لا تحتاج الخطة المدفوعة أو النتائج المباشرة.
4. افتح [GitHub Actions Secrets](https://github.com/Hero9994/tiktok-daily/settings/secrets/actions)، وأضف الأسرار الثلاثة: `BUFFER_API_KEY`، `OPENAI_API_KEY`، `FOOTBALL_DATA_API_KEY`. لا ترسل مفاتيحك أو كلمات المرور في المحادثة ولا تضعها في الملفات العامة.

يتولى الوكيل بعد ذلك تشغيل `discover`، وضبط `buffer_organization_id` و`buffer_channel_id` في `config.json`؛ هذه معرّفات إعداد وليست مفاتيح سرية. يمكن حفظها في Secrets إن رغبت. عند وجود عدة قنوات يجب تحديد حساب TikTok المقصود.

ثم يشغّل `doctor` للتحقق من الإعدادات، ويفعّل `enabled` و`allow_paid_openai` بعد مراجعة التكلفة، ويختبر منشورًا واحدًا ويؤكد حالة `sent` ورابطه. بعدها تعمل الجدولة دون فتح هذه المحادثة يوميًا. لا تُعد حالة `accepted` إثباتًا للنشر.

## الإعدادات المعتمدة

| الإعداد | القيمة/الاستخدام |
|---|---|
| `content_mode` | `auto`: مباريات ثم فيلم/مسلسل؛ `cinema`: أفلام ومسلسلات فقط؛ `art`: فن عام |
| `caption_suffix` | العبارة الثابتة أعلاه؛ توضع بعد الهاشتاغات في النهاية |
| `fixed_caption` | `null` للسماح بتغيير الوصف؛ يمكن جعله نصًا ثابتًا عند الطلب |
| `brand_name` و`card_style` | `TK SERVERS` و`black_gold` |
| `publish_time` و`timezone` | 18:00 بتوقيت `Europe/Berlin`؛ ضمن نافذة 12:00–20:00 التي طلبها المستخدم |
| `football_competitions` | دوري الأبطال، الإنجليزي، الإسباني، الألماني، الإيطالي، الفرنسي، كأس العالم وأوروبا |
| `hashtag_pool` و`fixed_hashtags` | يختار 5 هاشتاغات مرتبطة بالمنشور، دون هاشتاغات ثابتة افتراضيًا |
| `theme` و`style` | تفضيلات ترشيح الأعمال وأسلوب خلفية الصورة |
| `max_image_requests_per_month` | 31 افتراضيًا، ويشمل المحاولات الفاشلة؛ لا يمثل سقف فاتورة بالدولار |

التحضير يعمل **17:07 بتوقيت ألمانيا**، والنشر المجدول **18:00**. GitHub يستخدم منطقة `Europe/Berlin` في cron ويضبط الانتقال الصيفي؛ فحص التسليم عند الدقيقة 43 من كل ساعة. إذا عدّلت موعد النشر فعدّل توقيت التحضير أيضًا. GitHub قد يؤخر أو يسقط تشغيلًا، وقد يعطّل الجدولة بعد 60 يومًا دون نشاط؛ التشغيل المجاني ليس ضمانًا لخدمة لا تحتاج أي صيانة.

«الغد» هو اليوم التالي **لتاريخ النشر في ألمانيا**، وليس لتاريخ توليد الخلفية. يظهر توقيت ألمانيا ومكة محسوبًا من UTC لكل مباراة، ويضاف تنبيه (+1 يوم) عندما تكون المباراة في مكة في اليوم التالي. لا يُستنتج موعد تقريبي من الذكاء الاصطناعي: تُنشر مباريات `TIMED` فقط، وتُستبعد المؤجلة والملغاة. غياب المفتاح أو خطأ المصدر لا يعامل كغياب مباريات.

يتكرر فحص الجدول بعد توليد الخلفية وقبل تسليم الصور إلى Buffer؛ إن تغير الموعد تُعاد كتابة البطاقات دون توليد صورة مدفوعة جديدة. لا يتغير المنشور تلقائيًا بعد إرساله إلى Buffer، وقد تحدث تعديلات لاحقة من المنظّمين أو تأخر في تحديث الخطة المجانية؛ يذكر المنشور المصدر وأن المواعيد قابلة للتغيير.

## القالب والمعلومات

كل صورة نهائية **1080×1920 JPEG**، بإطار ذهبي، وشعار TK كتابي، وبطاقات عربية وخاتمة الهوية. الصور الفنية الخلفية يولّدها OpenAI اقتصاديًا بـ1024×1536 ثم تُحجّم محليًا؛ النص والمواعيد تُكتب بخط Noto Sans Arabic المرخّص OFL ليظهر العربي متصلًا. الخلفية الأصلية لا تمثل بوسترًا رسميًا أو صورة لاعب/ممثل. التقييمات وعدد الحلقات وصور الممثلين غير مضافة دون مصدر مناسب، ولا يزعم المشروع توفر بث لمباراة أو عمل غير متحقق.

يحتوي جدول المباريات 6 مواجهات في الصفحة؛ إذا زاد العدد يصبح المنشور carousel حتى 10 صور، دون إسقاط مباريات من البطولات المختارة. كلها تستعمل خلفية واحدة، فتظل تكلفة طلب الصورة واحدة. إن تجاوز الجدول 60 مواجهة يتوقف ويُطلب تعديل النطاق بدل نشر جدول ناقص.

المعلومات عن الأفلام والمسلسلات مأخوذة من ملخص Wikipedia؛ يحفظ عنوان المصدر ومعرّف الصفحة لمنع تكرار العمل رغم اختلاف الاسم. يمنع أيضًا تكرار تاريخ النشر للقناة، ويحفظ السجل في فرع `bot-state` قبل طلب Buffer. لا تحذف هذا الفرع أو تعدّله بالتوازي مع التشغيل.

## التكلفة والسلامة

- Buffer Free: API مجاني، مفتاح واحد و3,000 طلب/30 يومًا، 100 طلب/15 دقيقة، وصف انتظار 10 منشورات لكل قناة. لا نستخدم API القديم.
- GitHub Actions: مشغّلات قياسية في مستودع عام؛ لا يُرفع Actions artifact ولا تُستخدم مشغّلات مدفوعة.
- football-data.org Free: €0، 12 بطولة، 10 طلبات/دقيقة، مع تأخير في النتائج والجداول بحسب وصف الخطة. الخطة الأعلى ليست مطلوبة أو مفعّلة. المصدر مذكور على البطاقة وفي الوصف.
- OpenAI مدفوع: مخرجات `gpt-image-2` low portrait موثقة بـ$0.005 للطلب، أي $0.15 لمخرجات 30 طلبًا، **إضافةً إلى** مدخلات الصورة والنص وطلبات صياغة الأفكار والإعادات. medium بسعر مخرجات $0.041 للصورة. قد تختلف الفاتورة والضرائب والحد الأدنى للشحن؛ الأسعار قابلة للتغيير.
- يضاف إفصاح عن توليد الرسم الفني بالذكاء الاصطناعي. Buffer يرفض العلم الأصلي `isAiGenerated` على صور TikTok، لذلك لا نرسله. تستعمل الأوصاف إفصاحًا واضحًا وفق الإرشادات الرسمية. يفحص OpenAI Moderation المحتوى كحماية إضافية.
- المفاتيح في Secrets فقط. السجل والصور في المستودع العام؛ لا يتضمن السجل مفاتيح. تشغيل النشر على الفرع الافتراضي فقط، واختبارات PR لا تستخدم الأسرار.

## الفشل والتحقق

تعاد محاولات القراءات بتأخير تصاعدي، ولطلبات النص والصور حدود محفوظة قبل كل اتصال مدفوع. عند انقطاع رد `createPost` لا يعاد إرسال المنشور: يفحص المشروع منشورات Buffer، ويطابق العنوان والوصف لاستعادة المعرف، ثم يتوقف إن بقيت النتيجة غير مؤكدة. لا يوجد idempotency key على هذه mutation.

حالة `sent` تؤكد التسليم بحسب Buffer؛ `accepted` انتظار. ينتج تنبيه فشل Actions وقضية GitHub واحدة عند خطأ أو نشر بالإشعار/حاجة للموافقة أو تأخر أكثر من 90 دقيقة. فعّل إشعارات فشل Actions والبريد في حساب GitHub. إصلاح الصلاحيات ثم `verify` هو أول خطوة؛ لا تمسح السجل ولا ترسل ثانية قبل فحص Buffer عند نتيجة غامضة.

إيقاف `enabled` يمنع التشغيل الجديد، لكن الصور التي سبق جدولتها في Buffer تبقى؛ لإيقافها أوقف القناة أو احذف تلك المنشورات من Buffer أيضًا.

## تجربة محلية دون إنفاق

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m tiktok_daily doctor
python -m tiktok_daily preview
```

`preview` ينتج نموذج فيلم ونموذج مباريات ببيانات فرق وأوقات تجريبية معلَّمة بوضوح. الخلفية مرسومة محليًا، ولا تمثل توليد OpenAI أو نشر TikTok. الأمثلة موجودة في `examples/`. الاختبارات المحلية وخدمات HTTP المحاكاة لا تثبت نجاح نشر حي؛ الاختبار الحي ينتظر المفاتيح وربط TikTok.
